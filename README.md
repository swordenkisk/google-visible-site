# Google Visible Site

A responsive French-language landing page about presenting a business online
and helping potential clients discover its services through search.

## Features

- Responsive layout for desktop and mobile
- Mobile navigation with accessible state labels
- French landing-page copy based on the supplied project brief
- Basic page title, description, and social sharing metadata
- No build step, package manager, API keys, or server-side dependencies

## Run locally

Requirements: Python 3.

chmod +x setup.sh
./setup.sh
